The result matches this description: A single self-contained ui.html with an inventory screen (20 slots, stack counts, equippable tools, a detail area for the selected item) and a dialogue box (speaker name, typed-out text, up to three choices), both operable with arrows, Enter and Escape with a clearly visible focus. The visual direction is stated and specific to an 1890s lighthouse setting rather than a stock parchment-and-gold fantasy look or dark glass cards.
