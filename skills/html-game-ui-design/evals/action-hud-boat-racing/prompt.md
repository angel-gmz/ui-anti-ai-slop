Estoy haciendo un arcade de carreras de lanchas visto desde arriba, se llama "Brazo de Mar". El juego corre en Phaser 3 en un canvas de 1280x720 y quiero que el HUD sea HTML encima del canvas. Necesito: velocidad, barra de turbo (se gasta y se recarga), posición en la carrera (ej. 3 de 8), vuelta actual (2/3), tiempo de carrera, un aviso cuando vas en sentido contrario, y un menú de pausa (continuar, reiniciar, opciones, salir). Se juega con teclado o control. Dame un solo archivo HTML llamado hud.html con un canvas de relleno que dibuje algo parecido al agua para poder ver el HUD encima, y unos botones o teclas de prueba para simular que cambian los valores.
